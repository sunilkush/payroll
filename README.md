# Payroll SaaS (MERN)

Production-oriented multi-tenant payroll SaaS starter with company isolation, role/permission authorization, payroll engine, approval workflow, billing readiness, and employee self-service portal.

## Structure
- `backend/` Express + MongoDB API
- `frontend/` React + Redux + AntD + Tailwind app

## Run
### Backend
```bash
cd backend
npm install
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
